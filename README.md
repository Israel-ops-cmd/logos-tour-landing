# Logos Tour Viagens e Turismo

Landing page da Logos Tour, agência de viagens em Natal/RN.

- `index.html`: página única com CSS e JS embutidos (sem build).
- `img/`: fotos de Gramado e do Rio, logo, favicon e imagem de compartilhamento.
- As demais fotos de destinos vêm do Unsplash (licença gratuita para uso comercial).

Para publicar, basta servir a pasta como site estático (Vercel, sem configuração).
